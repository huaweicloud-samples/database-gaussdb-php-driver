# 兼容边界与故障排除

优先确认 PHP/扩展/ODBC 位数一致、驱动与服务端匹配，以及实际业务进程加载了正确配置。
本仓库不随附内部验收记录，连接示例成功不等于功能验收或生产认证。

| 现象 | 排查与处理 |
| --- | --- |
| 没有 `odbc` PDO 驱动 | 启用 PDO_ODBC，核对 CLI/FPM 的 ini、扩展目录和运行用户 |
| 找不到驱动/共享库 | 核对 ODBC 注册名、CPU 架构、文件权限及私有依赖 |
| TLS 失败 | 核对实例 TLS、CA 信任链、证书路径和主机名，不直接降低生产策略 |
| 数据库模式不匹配 | M 必须连 M/MYSQL 库，O/A/ORA 必须连 ORA 库；客户端模式不能转换数据库 |
| 布尔类型或值不符 | 显式标注 `ResultType::BOOLEAN`，自定义 DSN 设 `BoolsAsChar=1` 后重连；不要用强转掩盖问题 |
| 空串变为 NULL | 保留目标模式自身语义；ORA 空串可能为 NULL |
| 二进制为十六进制文本 | 仅对二进制列标记 `ResultType::BINARY_HEX` |
| lastInsertId 返回 IM001 | 不依赖该 ODBC 能力；采用业务主键或明确的数据库返回方式 |
| 时间戳丢失微秒 | 部分 ODBC 路径可能丢失精度；兼容层不能恢复已经丢失的信息 |
| TEXT/CLOB 长度或尾部 NUL 差异 | 按实例及字段类型验证；不无条件裁剪 NUL |
| SQLSTATE 报错 | 保留 SQLSTATE 和脱敏复现步骤，核对权限、类型和约束，不盲目重试 |
| 安装/卸载被拒 | 核对独立目录、安装清单和文件变更；不要用广泛递归删除命令 |

不承诺 ORM 完整适配、性能基准、自动故障切换、自动重连、连接池会话清理、所有存储过程 OUT 参数及用户自定义类型。
既有环境反馈的 M 模式重复布尔读取差异仍需在对应驱动组合复核；字符传输规避不能替代根因确认。
不要把局部验证通过表述为所有 Windows/Linux、PHP 或数据库组合已认证。

普通 Issue 请提供系统、架构、PHP 版本、驱动来源、数据库模式、脱敏 SQL 与实际 PHP 类型。
不要上传密码、私钥、云 AK/SK、客户数据或未经许可的厂商包。
安全问题按 [安全策略](../SECURITY.md)私下报告。
